This file contains the verbatim tool outputs from the two direct-choice
polling canaries (V1 baseline and V2 prompt-patched) that were run on
2026-05-16, prior to the V3 probability-vector primitive.

The on-disk synth_responses parquets for V1 and V2 in
build/out/stage_b/canary_W158_n100_20260516/ and
build/out/stage_b/canary_W158_n100_direct_20260516_v2/ are byte-identical
(sha256 verified). The original V1 parquets were overwritten before this
project went under git tracking (initial commit dbba646, 2026-05-17). The
text outputs preserved below are the authoritative record of V1 and V2
topline + per-question entropy values; the lab-notebook narrative at
docs/v1-v2-canary-provenance.md is the contemporaneous transcription.

Forensic chain of custody: source-of-truth tool output was captured in
the project's local Claude Code session JSONL. Lab notebook (subsequently
sanitized into docs/sanitized-chronology.md and the provenance document)
transcribed the values from that tool output the same day. The forensic
addendum at docs/v1-v2-canary-provenance.md documents the sha256 identity
check confirming the disk-V1 directory contains V2-era data.
